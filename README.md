# Relation-Partial_Order-Explorer
## Overview
It is a tool designed to analyze mathematical relations and explore properties of partial orders. The application allows users to input elements and relations, then automatically checks important properties such as reflexivity, symmetry, and transitivity.

## Features
Input custom sets and relations<br>
Check relation properties (reflexive, symmetric, transitive)<br>
Identify maximum and minimum elements<br>
Determine whether the relation forms a partial order<br>
Generate Hasse diagrams for visualization<br>

## Technologies Used
R<br>
Graph visualization libraries<br>
Mathematical relation analysis<br>

## How to Run
Open the project in RStudio.<br>
Run the main R script.<br>
Enter the elements and relations as prompted.<br>
View the computed properties and generated diagrams.<br>
